システム構成図

Concept Cartographer — どこで何が動き、何がこの Mac の外に出るのか

境界の要点 (何が Mac の外に出るか)

  • 出るもの: Foundry へのプロンプト (ローカル資料の抜粋・概念ラベル・検証の問い) と、その JSON 応答だけ
  • 出ないもの: 生成した地図・編集履歴・評価・索引・学習内容 — すべて graphs/ と logs/ にローカル保存
  • M365 の資料: 本文は Foundry 側の Work IQ が本人権限で読む (あなたが読めるものだけ)。こちらへ返るのは概念と根拠の逐語引用
  • 公開 API (arXiv 等): 既定 OFF。明示的に有効化したときだけ・送信は概念ラベルのみ・全件を記録

この構成の設計原則 — LLM は判断が要るところだけ (読む・抜く・検証する)。構造化・レイアウト・記号変換・再構成は決定的コードが担い、同じ入力からは必ず同じ地図が出ます。詳しい処理の流れは 説明ページの「しくみ」 へ。
この構成図は 抽出 v2 + レスポンシブ (2026-08-07) 時点の実装に基づきます。機能追加・仕様変更の際にこのページも更新されます。
