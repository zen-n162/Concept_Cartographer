Concept Cartographer 散らばった研究資料を、1枚の「研究の地図」にする

論文・ノート・提案書・チャット……研究の情報はあちこちに散らばります。 Concept Cartographer は、チャットで「今週の研究を概念地図として整理して」と頼むだけで、 本人の OneDrive / SharePoint から資料を集め、概念どうしの関係と 「まだ分かっていない場所（ギャップ候補）」まで描いた手描き風の地図を返す社内AIエージェントです。

PoC 動作実証済み（2026-08-05 実測） Microsoft Foundry ＋ GPT-5.6 で稼働 出力は Excalidraw — 手で描き直せる

図 1 — 何ができあがるのか

ただの相関図ではありません。テーマごとの「島」に概念を置き、関係の種類を線の描き分けで示します。 情報が足りない場所は「ギャップ候補」として薄く・破線で描かれ、次に調べるべき場所が一目で分かります。

図 3 — 中の仕組み：4体の分業と「契約書」

信頼性の核は役割の分離です。意味の判断（何が概念か、どんな関係か）はAIが行い、 座標計算と描画は毎回同じ結果になる計算コードが行います。両者の間を layout_plan.json という中間契約がつなぎ、最後に別のAIが答案を採点します。

設計のこだわり — 4つの約束

座標はAIに計算させない

AIが決めるのは「何が概念で、どうつながるか」まで。配置・作図は毎回同じ結果になる計算コードが担当し、再現性を保証します。

描いた本人に検証させない

描画とは別のモデル（gpt-5.6-terra）が、計画と画面上の全要素を機械的に突合します。合格（PASS）するまで完成と言いません。

空白を断定しない

証拠が薄いテーマは「ギャップ候補」として破線・半透明で描き、結論に見せません。確定するのは人間の役目です。

読むのは本人の権限の範囲だけ

資料の読み取りは Work IQ 経由で、依頼した本人がアクセスできる範囲に限定。描画サーバーはQST閉域のVMで、インターネットに一切公開していません。

図 4 — 実行の2モード（どちらも動作確認済み）

はじめての人のための用語ミニ辞典

概念地図Concept Map
概念どうしを線で結び、線に「因果」「相関」など関係の意味を書き込む図法（Novak, 1972）。放射状のマインドマップと違い、任意の概念間に意味付きの関係を張れるため、研究の構造を表すのに向く。
ギャップ候補Gap
集めた資料の中で言及が薄い・検証されていないテーマ。地図上では破線・半透明の島として描かれ、「次に読むべき文献・やるべき実験」を考える手がかりになる。
Work IQ
Microsoft 365（OneDrive / SharePoint / Teams など）のデータをAIが安全に読むための仕組み。読めるのは依頼した本人がもともとアクセスできる範囲だけ。
Excalidraw
手描き風の作図ツール（オープンソース）。生成された地図は画像ではなく編集可能なデータなので、研究者が自分の手で描き直しながら考え続けられる。
